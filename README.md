FOURIERSTUDIO – KURULUM
-----------------------
1. Tüm dosyaları indirin.
2. Dosyaların tamamının aynı klasörde olduğundan emin olun.
3. Python ve VS Code'u kurun.
4. VS Code ile bu klasörü açın.
5. Terminali açın ve aşağıdaki komutları sırayla çalıştırın:
    pip install numpy scipy sounddevice numba PyQt6
   
7. Main.py dosyasını açın.
8. F5 tuşuna basarak programı çalıştırın.
