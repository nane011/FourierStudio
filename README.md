FOURIERSTUDIO – KURULUM

1. Tüm dosyaları indirin.
2. Dosyaların tamamının aynı klasörde olduğundan emin olun.
3. Python ve VS Code'u kurun.
4. VS Code ile bu klasörü açın.
5. Terminali açın ve aşağıdaki komutları sırayla çalıştırın:

pip install numpy
pip install scipy
pip install sounddevice
pip install PyQt6

6. Main.py dosyasını açın.
7. F5 tuşuna basarak programı çalıştırın.

Not:
Program hobi amaçlı geliştirilmiştir. Bazı denklemlerde veya çok fazla denklem
aynı anda çalıştırıldığında performans sorunları yaşanabilir.

İyi çalışmalar <3
